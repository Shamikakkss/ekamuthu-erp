# 📘 EkamuthuERP
> **Cloud-Based Community Mutual Aid & Death Donation Society Management System** (*මරණාධාර සමිති ERP පද්ධතිය*)

EkamuthuERP is an Enterprise Resource Planning (ERP) system designed for managing community mutual aid societies. It handles member registration, monthly subscription payments, automatic late fine calculations, bank receipt uploads, and death benefit claim processing.

## 🚀 Quick Start Guide

### 1. Backend Setup
```bash
cd backend
npm install
# Configure .env (PORT=5000, MONGO_URI, JWT_SECRET)
npm run dev
```

### 2. Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
